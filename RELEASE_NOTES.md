First recorded standalone release of the earlier ADM1 biomethane workflow.

- Preserves the existing mass-based ADM1/R1–R4 source and input tables.
- Reconstructs TEA, partial GHG, finite-grid optimization, robustness and
  sensitivity interfaces from the July–August project notes.
- Includes an executed four-point example, 64 descriptive sensitivity draws,
  five passing light integration tests and source/result hashes.
- Provides an installable Python package and command-line interface.

This is a research-code record. It does not claim complete historical numerical
reproduction, independent biological validation, a global optimum or a full
product LCA. No DWSIM, Aspen or downstream hydrogen optimization is included.

Install with `python -m pip install adm1-tea-lca`.
Use `adm1-tea-lca demo --output runs/demo` for a small recorded workflow.
